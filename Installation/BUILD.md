# Guia de Instalação - Objeto de Aprendizagem
## Thermal Evaporation Plant

Siga os passos abaixo cuidadosamente para configurar o ambiente e executar o objeto de aprendizagem corretamente.

### Pré-requisitos
Certifique-se de ter o **Minecraft** e o **Java** instalados corretamente no seu computador.

---

### Passo 1: Instalação do Forge
1. Localize o arquivo instalador fornecido: `forge-1.20.1-47.4.10-installer.jar`.
2. Execute este arquivo (dê um clique duplo).
3. Na janela que abrir, certifique-se de que a opção **"Install Client"** esteja selecionada e clique em **OK**.
4. Aguarde o término da instalação e clique em OK novamente.

### Passo 2: Inicialização Inicial
Antes de copiar os arquivos do projeto, é necessário criar as pastas nativas do Forge.

1. Abra o **Minecraft Launcher**.
2. Selecione a instalação/perfil do **Forge 1.20.1** que acabou de ser criada.
3. Clique em **Jogar**.
4. Assim que o jogo abrir e chegar ao menu principal, **feche o jogo**.

### Passo 3: Instalação do Projeto (Arquivos do GitHub)
Agora vamos substituir os arquivos de configuração pelos arquivos do objeto de aprendizagem.

1. Baixe/Copie a pasta `.minecraft` disponibilizada neste repositório do GitHub.
2. No seu computador, pressione as teclas `Windows + R`, digite `%appdata%` e aperte Enter.
   * Isso abrirá a pasta `C:\Users\[SeuUsuario]\AppData\Roaming`.
3. Localize a sua pasta `.minecraft` original.
4. **Cole** a pasta `.minecraft` que você baixou do GitHub dentro desta pasta `Roaming`, substituindo/mesclando com a existente.
   * *Nota: Se o sistema perguntar se deseja substituir arquivos, clique em "Sim".*

### Passo 4: Acessando o Mapa
1. Abra o **Minecraft Launcher** novamente.
2. Certifique-se de estar usando o perfil do **Forge**.
3. Clique em **Jogar**.
4. No menu "Um Jogador" (Singleplayer), localize e entre no mundo **"Thermal Evaporation Plant"**.

---
**Bom estudo!**
